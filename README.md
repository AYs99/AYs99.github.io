# Abdalla Yassein — Backend Engineer Portfolio

A responsive, static portfolio website built from the resume provided in ChatGPT.

## Run locally
Open `index.html` in a browser. For a local server, run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Before publishing
- Add a professional portrait if desired. The current design uses a technical illustration instead, so no photo is fabricated.
- Review the public metrics and technical descriptions for employer/client confidentiality.
- Confirm the LinkedIn URL and update it if needed.
- `resume.pdf` is included as the resume download.
- Replace any case-study text that you cannot publicly disclose.
- This is a static site; no backend or tracking is used.

## Deploy
Upload the contents of this folder to a static hosting provider such as GitHub Pages, Cloudflare Pages, or Netlify. No build step is required.
